# Sources and scope

The **Skillsoft Percipio** training path had 22 course-completion records. These are training completions, not an RHCSA (EX200) exam certification. The coursework covered RHCSA-oriented topics, and I used a Red Hat Enterprise Linux **10** VM for my practical exercises.

My original notebook has 13,264 lines. The published notes split it into 22 corresponding sections, select meaningful terminal examples, remove secrets and excessive console output, and improve explanations. This is an edited notebook rather than a complete raw-terminal dump.
